# Implementation Plan: Kanban Claims Board

**Branch**: `002-kanban-claims-board` | **Date**: 2026-11-17 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/002-kanban-claims-board/spec.md`

## Summary

Replace the existing sidebar + claim list + dashboard layout with a full-page kanban board at the root path. Claims are grouped into columns by status, filtered by service period date range and patient name search via header controls. Cards are display-only; all actions happen on the existing claim detail page.

## Technical Context

**Language/Version**: TypeScript 7.0 / React 19

**Primary Dependencies**: Mantine v9 (`@mantine/core`, `@mantine/dates`), TanStack Router, Zustand, dayjs, Tabler Icons

**Storage**: In-memory Zustand store with seed data (no backend)

**Testing**: Vitest (unit), Playwright (e2e)

**Target Platform**: Desktop web browser (Vite dev server)

**Project Type**: Single-page web application (SPA)

**Performance Goals**: Board renders <=200 claims across 6 columns within 2 seconds

**Constraints**: No drag-and-drop; display-only cards; all actions on detail page

**Scale/Scope**: ~30 claims in seed data, 6 status columns, 3 new components
